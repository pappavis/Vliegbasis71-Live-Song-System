# ☕ Table Session

> **Een tafeltje, twee stoelen, een gitaar en één vraag kunnen genoeg zijn om samen iets te maken.**

De Table Session is de kleinste fysieke vorm van de Vliegbasis71 Live Song Workbench.

Geen podium nodig.

Geen studio.

Geen workshopruimte.

Geen muzikaal talent van de deelnemer.

---

# 🎯 Het concept

```text
        OPENBARE PLEK
             │
             ▼
      ┌───────────────┐
      │    TAFEL      │
      │ ☕         ☕  │
      │               │
      │  STORY → SONG │
      └───────────────┘
        🪑         🪑
```

De facilitator zit met een kleine tafel op bijvoorbeeld:

- een plein;
- park;
- cultureel evenement;
- Toastmasters-bijeenkomst;
- festival;
- buurthuis;
- cafésetting waar dit toegestaan is.

Het doel is niet:

> "Kijk naar mijn optreden."

Het doel is:

> "Zullen we samen iets maken?"

---

# 🧰 Minimal Field Kit

## Absolute minimum

```text
🎸 gitaar
📱 telefoon
🪑 plek om te zitten
🧠 eenvoudige methode
```

Dat is genoeg.

# 📋 De A6-kaart

De kaart moet in enkele seconden begrijpelijk zijn.

Voorzijde:

```text
┌────────────────────────────┐
│ 🎵 Vliegbasis71           │
│                            │
│ TELL A SMALL STORY         │
│        ↓                   │
│ CHOOSE A FEW WORDS         │
│        ↓                   │
│ WE MAKE A TINY SONG        │
│                            │
│ You don't need to sing.    │
│                            │
│ 3–5 minutes                │
└────────────────────────────┘
```

Achterzijde:

```text
┌────────────────────────────┐
│ HOW IT WORKS               │
│                            │
│ 1. Tell                    │
│ 2. Choose                  │
│ 3. Build                   │
│ 4. Play                    │
│ 5. Remix — maybe 🙂        │
│                            │
│ Your story stays yours.    │
└────────────────────────────┘
```

# 🧠 Waarom klein?

Een groot bord met twintig instructies creëert werk.

De kaart moet vooral deze vraag beantwoorden:

> "Wat gebeurt hier?"

---

# 👋 De opener

Niet:

> "Mag ik u interviewen voor mijn songwriting research?"

Beter:

> "Hoi, ik test iets met verhalen en muziek. Jij vertelt een klein verhaal en we maken daar in een paar minuten samen iets muzikaals van. Zin om het te proberen?"

Of nog kleiner:

> "Wil je zien of we van één klein verhaal in vijf minuten een liedje kunnen maken?"

---

# 🛡️ Geen druk

Een persoon mag:

```text
NEE
```

zeggen.

Dat is een volledig succesvolle interactie.

```text
UITNODIGING
    ↓
   NEE
    ↓
"Dankjewel!"
    ↓
 KLAAR
```

Geen overtuiging.

Geen tweede verkoopronde.

---

# 🗣️ Begin klein

Vraag niet meteen:

> "Wat is het diepste trauma uit jouw leven?"

Begin bijvoorbeeld met:

- iets leuks dat deze week gebeurde;
- een plek waar iemand graag komt;
- een kleine overwinning;
- een nieuwe stap;
- iets waar iemand naar uitkijkt;
- een grappige herinnering;
- een onverwachte ontmoeting.

---

# 🔐 Persoonlijke verhalen

De deelnemer bepaalt hoeveel hij of zij deelt.

```text
LIGHT
  │
  ├── leuke herinnering
  ├── vakantie
  ├── hobby
  │
  ▼
PERSONAL
  │
  ├── verandering
  ├── droom
  ├── uitdaging
  │
  ▼
DEEP
```

De facilitator hoeft niemand naar `DEEP` te sturen.

---

# 🎙️ Opnemen

Vraag expliciet toestemming voordat audio/video wordt opgenomen.

Bijvoorbeeld:

> "Vind je het goed als ik alleen het liedje even opneem zodat we het kunnen terugluisteren?"

Geen toestemming?

Dan:

```text
LIVE ONLY
```

De sessie werkt nog steeds.

---

# 🎵 Het moment

De tafel moet uiteindelijk verdwijnen uit de aandacht.

```text
vreemden
   ↓
gesprek
   ↓
woorden
   ↓
ritme
   ↓
gelach / proberen
   ↓
muziek
```

Dat is de ervaring.

---

# 🔄 Remix Moment

Na de eerste versie:

> "Wil je horen hoe exact hetzelfde verhaal ineens als iets totaal anders klinkt?"

Bijvoorbeeld:

```text
ACOUSTIC
   ↓
SHOEGAZE
```

of:

```text
SLOW
   ↓
TECHNO
```

Niet verplicht.

Wel een sterk speelmoment.
