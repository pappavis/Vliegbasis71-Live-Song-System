# 📴 Offline First

> **Een live liedje moet ook kunnen ontstaan wanneer internet, AI en zelfs de laptop verdwijnen.**

De Vliegbasis71 Live Song Workbench wordt daarom ontworpen volgens:

```text
HUMAN FIRST
    ↓
PAPER / MEMORY
    ↓
LOCAL WEB APP
    ↓
LOCAL AI
    ↓
OPTIONAL ONLINE SERVICES
```

Niet andersom.

---

# 🎯 Waarom Offline First?

De Workbench wordt uiteindelijk gebruikt op plekken zoals:

- park;
- plein;
- Toastmasters;
- camping;
- café;
- repetitieruimte;
- straat;
- trein;
- workshop;
- kleine live performance.

Daar is internet niet gegarandeerd.

En zelfs wanneer internet beschikbaar is:

```text
internet
   ≠
betrouwbaar onderdeel
van een live performance
```

# 🛟 Graceful Degradation

De Workbench moet altijd één niveau kunnen terugvallen.

```text
ONLINE AI FAIL
      ↓
LOCAL AI

LOCAL AI FAIL
      ↓
MANUAL WEB APP

WEB APP FAIL
      ↓
A6 CARD

PHONE FAIL
      ↓
GUITAR + MEMORY
```

Dit is geen noodoplossing.

Dit **is onderdeel van het ontwerp**.

---

# 🎸 Performance Rule

Wanneer technologie tijdens een sessie langer dan ongeveer enkele seconden aandacht vraagt:

```text
STOP DEBUGGING
     ↓
FALL BACK
     ↓
KEEP PLAYING
```

De deelnemer kwam niet kijken naar:

```text
ollama logs
npm
JSON parser errors
Wi-Fi
```

De deelnemer kwam iets maken.

---

# 🧭 Het menselijke systeem blijft leidend

```text
STORY
  ↓
MEANING
  ↓
WORDS
  ↓
MUSIC
```

Technologie ondersteunt dat proces.

Dus nooit:

```text
MODEL OUTPUT
    ↓
"dit is blijkbaar jouw verhaal"
```

Wel:

```text
MODEL OUTPUT
    ↓
"welke hiervan voelt goed?"
    ↓
HUMAN CHOICE
```
