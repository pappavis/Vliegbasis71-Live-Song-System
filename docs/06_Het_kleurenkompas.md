# 🌍 Hoofdstuk 6
# 🎨 Het Kleurenkompas

> _"Goede muzikanten onthouden geen duizenden noten.
> Ze voelen waar de zwaartekracht zit."_

---

# ❤️ Dit hoofdstuk veranderde mijn manier van denken

Tot een paar dagen geleden dacht ik eigenlijk:

> "Welke toonladder moet ik nu spelen?"

Dat bleek de verkeerde vraag.

De juiste vraag is:

> **"Waar wil deze melodie naartoe?"**

Dat lijkt een klein verschil.

Maar het verandert alles.

---

# 🌳 Stel...

Je loopt door een bos.

Er zijn honderden paadjes.

Maar ergens ligt jouw huis.

Onbewust loop je steeds weer richting huis.

Muziek werkt precies zo.

---

# Iedere akkoord heeft een thuis

Wanneer Gitaar 1 speelt:

```
Em
```

dan voelt jouw oor:

```
E
```

als thuis.

Niet omdat iemand dat bedacht heeft.

Maar omdat je hersenen spanning willen oplossen.

---

# 🎸 De muzikale zwaartekracht

Ik noem dit:

## Muzikale zwaartekracht.

Iedere akkoord trekt bepaalde noten naar zich toe.

Net zoals de aarde alles aantrekt.

---


# 🌈 Waarom klinkt dit mooi?

Omdat jouw melodie "landt".

Niet zweeft.

Vergelijk het met een vliegtuig.

Iedere vlucht wil uiteindelijk landen.

Niet eeuwig rondjes vliegen.

---

!!! tip "✈️ Vliegbasis71"

    Goede melodieën landen regelmatig.

---

# 🟢 Groene noten

Groen betekent:

> Hier mag je stoppen.

Bijvoorbeeld:

Gitaar:

```
Em
```

Melodie:

```
E

...

G

...

B
```

Alle drie voelen prettig.

---

# 🟡 Gele noten

Geel betekent:

> Ik wil ergens heen.

Bijvoorbeeld:

```
A
```

Tijdens Em.

Dat klinkt mooi.

Maar...

je voelt bijna automatisch:

> "Speel nog één noot."

---

# 🔴 Rode noten

Rood betekent:

Spanning.

Niet fout.

Maar je wilt meestal niet eindigen.

Bijvoorbeeld:

```
F
```

boven Em.

Dat schuurt.

En juist daardoor...

kan het soms geweldig zijn.

---

# 📒 Samenvatting

Vanaf vandaag denk je niet meer:

> "Welke toonladder speel ik?"

Maar:

> **"Waar wil mijn melodie landen?"**

Dat is een compleet andere manier van muziek maken.

En precies daar begint improviseren.
