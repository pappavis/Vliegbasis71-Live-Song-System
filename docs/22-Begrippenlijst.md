# Begrippenlijst

---

# 🌳 Waarom een begrippenlijst?

Veel gitaarboeken gebruiken moeilijke woorden.

Daardoor denken veel mensen:

> "Muziektheorie is niets voor mij."

Dat is jammer.

In dit boek vertalen we moeilijke termen naar gewone mensentaal.

Later krijgt deze begrippenlijst ook een centrale plaats in de online documentatie. # 🎸 Akkoord

Een groep noten die tegelijkertijd wordt gespeeld.

Voorbeeld:

```
Em

=

E
G
B
```

Denk aan:

🏠 het huis.

De melodie woont erin.

---

# 🎵 Arpeggio

De noten van een akkoord.

Maar...

één voor één gespeeld.

Dus:

In plaats van:

```
E G B
```

tegelijk,

speel je:

```
E

G

B
```

achter elkaar.

---

# 🥁 Backbeat

De nadruk op tel:

```
2

4
```

Hierdoor gaat muziek "grooven".

---

# 🎼 Barré-akkoord

Een akkoord waarbij één vinger meerdere snaren indrukt.

Moeilijker.

Maar heel krachtig.

---

# 🎼 BPM

Beats Per Minute.

Het tempo.

Voorbeeld:

```
60 BPM

=

1 tel per seconde
```

Jouw favoriete oefentempo:

```
88 BPM
```

---

# 🌈 Chord Tone

Een akkoordtoon.

Dus:

```
1

3

5
```

Dit zijn meestal jouw:

🟢 groene noten.

---

# 🎹 Diatonisch

Alle noten blijven binnen dezelfde toonsoort.

Bijvoorbeeld:

```
E mineur
```

Dan gebruik je:

```
E

F#

G

A

B

C

D
```

Je hoeft dus niet telkens een nieuwe toonladder te kiezen.

---

# 🎸 Fingerpicking

Met je vingers spelen.

In plaats van een plectrum.

---

# 🎵 Groove

Dat gevoel waardoor mensen automatisch mee gaan bewegen.

Groove is moeilijk uit te leggen.

Maar makkelijk te voelen.

---

# 🎸 Happy Strummer

De doelgroep van dit boek.

Iemand die:

✅ open akkoorden kent

✅ een paar barré-akkoorden kent

✅ ritmes kan spelen

✅ plezier belangrijker vindt dan perfectie

---

# 🎧 Layer

Een opname op de looper.

Voorbeeld:

Laag 1

→ akkoorden

Laag 2

→ melodie

Laag 3

→ bas

Laag 4

→ percussie

---

# 🔁 Looper

Een apparaat dat jouw spel opneemt.

Daarna speelt hij het eindeloos terug.

Daardoor kun je in je eentje meerdere gitaarpartijen opbouwen.

---

# 🎵 Melodie

De noten die mensen meestal onthouden.

De melodie "zingt".

---

# 🎼 Maat

Een groep tellen.

Vaak:

```
1

2

3

4
```

---

# 🎸 Octaaf

Dezelfde noot.

Maar hoger of lager.

Bijvoorbeeld:

```
lage E

↓

hoge E
```

Het blijft een E.

Alleen de hoogte verandert.

---

# 🎼 Palm Mute

Je legt de zijkant van je hand zacht tegen de snaren.

Daardoor ontstaat:

```
chug

chug

chug
```

---

# 🎵 Pentatoniek

Een toonladder met vijf noten.

Heel populair.

Maar...

niet noodzakelijk om met dit systeem te beginnen.

---

# 🍝 Pesto

Het belangrijkste woord van dit boek.

De metafoor.

Akkoorden zijn:

🍝 pasta

Melodie is:

🌿 pesto

Zonder pesto...

is het eten minder spannend.

---

# 🎸 Progressie

Een reeks akkoorden.

Bijvoorbeeld:

```
Em

C

G

D
```

# ❤️ De belangrijkste definitie

## Muziek

Muziek is niet:

veel noten.

Muziek is niet:

moeilijke theorie.

Muziek is:

iets voelen...

en dat gevoel met anderen delen.
