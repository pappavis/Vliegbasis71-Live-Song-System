# 🛠️ Waarom Material for MkDocs?

Voor dit project kiezen we **Material for MkDocs**.

Waarom?

Omdat het uitstekend geschikt is voor grote documentatieprojecten met een duidelijke navigatiestructuur, krachtige zoekfunctie en ondersteuning voor moderne Markdown-componenten. # 🌐 Publiceren

Wanneer alles gereed is:

```bash
mkdocs serve
```

voor lokaal testen.

Daarna:

```bash
mkdocs build
```

En uiteindelijk:

```bash
mkdocs gh-deploy
```

om de documentatie rechtstreeks naar GitHub Pages te publiceren.  [oai_citation:3‡MkDocs](https://www.mkdocs.org/user-guide/deploying-your-docs/?utm_source=chatgpt.com)
