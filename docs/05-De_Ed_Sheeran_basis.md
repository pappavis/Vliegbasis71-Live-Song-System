# 🌍 Hoofdstuk 5 — Recept 2
# 🎸 De Ed Sheeran Basis

> _"Vier eenvoudige akkoorden kunnen een stadion vullen."_

---

# 🎯 Doel

In dit hoofdstuk ga je leren hoe je uit vier open akkoorden een complete live-song kunt bouwen.

Niet kopiëren.

Maar hetzelfde **denkproces** gebruiken.

Na dit hoofdstuk kun je tientallen liedjes bouwen met precies dezelfde methode.

---

# 🌳 Het recept

## Akkoorden

```
Em | C | G | D
```

Dit is misschien wel één van de meest gebruikte akkoordprogressies ter wereld.

Niet omdat hij bijzonder ingewikkeld is.

Maar omdat hij werkt.

---

# 🍝 Ingrediënten

## Laag 1

Open akkoorden.

```
Em

↓

C

↓

G

↓

D
```

Rustig.

Niet haasten.

---

## Tempo

```
88 BPM
```

Waarom?

Omdat vrijwel iedereen daar prettig op kan lopen.

En dus ook prettig op kan luisteren.

!!! tip "🌳 Wandelsnelheid"

    Goede popmuziek voelt vaak als een ontspannen wandeling.
