    🚀 Git Workflow

    Voorbeeld:

    git add .

git commit -m "Nieuw recept toegevoegd"

git push

    Kleine, duidelijke commits maken het project later makkelijker te onderhouden.

    🌐 Publiceren

    Wanneer alles gereed is:

    mkdocs serve

    voor lokaal testen.

    Daarna:

    mkdocs build

    En uiteindelijk:

    mkdocs gh-deploy

    om de documentatie rechtstreeks naar GitHub Pages te publiceren. oai_citation:3‡MkDocs
