# 🌳 Welkom

Welkom bij het **Vliegbasis71 Live Song System**.

Dit project is ontstaan vanuit één eenvoudige vraag:

> **Hoe kan een Happy Strummer binnen enkele minuten een compleet live-lied bouwen, zonder afhankelijk te zijn van backingtracks, AI of een band?**

Na honderden uren experimenteren met:

- 🎸 akoestische gitaar
- 🎛️ loopers
- 🎵 melodieën
- 🟢 veilige noten
- 🌳 spelen in het park
- 🎤 Toastmasters
- ❤️ Ed Sheeran's live-looping

ontstond langzaam een compleet systeem.

Niet om ingewikkelder te maken.

Maar juist eenvoudiger.

# 🚀 Snel starten

Clone de repository:

```bash
git clone https://github.com/<jouw-account>/Vliegbasis71-Live-Song-System.git

cd Vliegbasis71-Live-Song-System
```

Installeer MkDocs Material:

```bash
python3 -m pip install mkdocs-material
```

Start de lokale documentatie:

```bash
mkdocs serve
```

Open daarna:

```
http://127.0.0.1:8000
```

Material for MkDocs ondersteunt een snelle lokale preview (`mkdocs serve`) en het publiceren naar GitHub Pages (`mkdocs gh-deploy`).  [oai_citation:0‡MkDocs](https://www.mkdocs.org/user-guide/writing-your-docs/?utm_source=chatgpt.com)

mkdocs gh-deploy
