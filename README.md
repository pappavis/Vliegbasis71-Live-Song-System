# 🌳 Welkom

Welkom bij het **Vliegbasis71 Live Song System**.

Dit project is ontstaan uit één simpele droom:

> **Iedere Happy Strummer moet binnen enkele minuten een compleet live lied kunnen bouwen.**

Geen complete band.

# ⚡ Quick Start

Clone de repository:

```bash
git clone https://github.com/<jouw-gebruikersnaam>/Vliegbasis71-Live-Song-System.git

cd Vliegbasis71-Live-Song-System
```

Maak een virtuele omgeving:

```bash
python3 -m venv .venv

source .venv/bin/activate
```

Installeer MkDocs Material:

```bash
pip install mkdocs-material
```

Start lokaal:

```bash
mkdocs serve
```

Open vervolgens:

```
http://127.0.0.1:8000
```

MkDocs zet relatieve Markdown-links automatisch om naar de juiste HTML-pagina's tijdens het bouwen van de site.  [oai_citation:1‡MkDocs](https://www.mkdocs.org/user-guide/writing-your-docs/?utm_source=chatgpt.com)

---

# 🌍 Publiceren

```bash
mkdocs build
```

of direct naar GitHub Pages:

```bash
mkdocs gh-deploy
```
