# 🤝 Contributing

Welkom!

Wat leuk dat je wilt bijdragen aan het Vliegbasis71 Live Song System.

## ❤️ Filosofie

Iedere bijdrage moet bijdragen aan:

- eenvoud
- plezier
- muzikaliteit
- toegankelijkheid

Niet:

- moeilijkere theorie
- onnodige complexiteit
- elitair taalgebruik
